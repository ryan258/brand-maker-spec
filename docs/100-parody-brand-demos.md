# 100 Parody Brand Demos

Copy-and-paste briefs for demoing the generator's comedic range. Every brand here is
invented, and every **Parody target** is a category, convention, or behavior — not a
real company. That keeps the output original and non-infringing, and it maps directly
onto the legacy `parody_target` field, which the prompt defines as "the category,
convention, or alternative this brand reacts against."

For sincere, real-world briefs see
[`100-awesome-brand-demos.md`](100-awesome-brand-demos.md).

## How to use one

1. Start the app (`uv run brand-maker`) and open `http://127.0.0.1:8000`.
2. Quick path: paste the **name** into the homepage generator and hit generate.
3. Full path: paste the name into *Brand or working name*, the fenced block into
   *What do you already know?*, then **Create workspace** →
   **Generate or refresh complete draft**.
4. Paste the **Logo** line into *Extra instructions* on the logo card.

```bash
curl -X POST http://127.0.0.1:8000/brand \
  -H 'Content-Type: application/json' \
  -d '{"brand_name":"Circle Back Industries"}'
```

The joke lands harder when the brand plays it completely straight. Every brief below
is written as if the brand does not know it is funny.

## Remix modifiers

Append any line below to push the generator further:

```text
Constraint: The brand must never acknowledge that it is a joke.
Constraint: All copy reads like a real press release from a real communications team.
Constraint: The palette must look like a legitimate Series B startup.
Constraint: The tagline must survive being read aloud by an unamused executive.
Posture: Play it completely straight. No winks, no puns, no self-aware asides.
Posture: Go absurdist. The internal logic must still hold from top to bottom.
Anti-goal: Do not reference any real company, product, person, or trademark.
Anti-goal: Do not explain the joke anywhere in the output.
Extension: Add three fake product names and one 30-second commercial script.
```

## A note on targets

Every `parody_target` here names a category, convention, or behavior. Keep it that way
when you write your own: satirizing a *practice* produces original brands, while cloning
a real company's name and identity produces a legal problem and a worse joke.
